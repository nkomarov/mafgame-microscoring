# Mafia Game Micro-scoring

Алгоритм начисления индивидуальных баллов за проверяемые события в спортивной мафии.

## Документация

1. [Правила и веса событий](scoring-rules.md) — таблицы начислений, условия и исключения.
2. [Сбор данных и порядок расчёта](data-collection.md) — входные данные, последовательность обработки и требования к проверке.
3. [Открытые вопросы](open-questions.md) — решения, которые ещё нужно формализовать.
4. [Обезличенный пример расчёта](data/game-2026-11-13.md) — демонстрация на десяти игроках без реальных имён.

## Основной принцип

Вычислять баллы из протокола событий, а не вводить итоговые оценки вручную. Каждое начисление должно иметь основание: событие, игрок, применённое правило, баллы.

Пример не является полным протоколом соревнования: некоторые исходные события отсутствуют, а отдельные допущения явно отмечены. Неизвестные данные нельзя автоматически трактовать как отсутствие события.

Репозиторий предназначен для разработки алгоритма. Не добавлять персональные данные и реальные ники участников.
